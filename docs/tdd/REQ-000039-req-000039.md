## Detailed Design

### Module: `hello.py` (repo root)
A two-element module: the `greet` function definition and a `__main__` guard.

**Pseudocode (NOT implementation; reproduced verbatim because the design IS the implementation):**
```
def greet(name: str = "world") -> str:
    return f"hello {name}"


if __name__ == "__main__":
    print(greet())
```

Design notes traceable to PRD:
- Default argument literal is `"world"` (double-quoted) — matches existing style and FR-2.
- f-string `f"hello {name}"` — single space between `hello` and `name`, no punctuation, no capitalization changes (NG6, FR-3, FR-4, FR-5).
- Return annotation `-> str` and parameter annotation `name: str = "world"` (NFR-3).
- No module-level statements other than `def greet(...)` and the `if __name__ == "__main__":` block — guarantees FR-8 / NFR-7 (importable without side effects, satisfies AT-5).
- `print(greet())` uses Python's default `end="\n"` to satisfy R-4 / FR-7 / NFR-6 / AT-3.

### Module: `test_hello.py` (repo root)
Three pytest test functions. Imports `greet` directly from the `hello` module (TC-5: test discovery via default pytest collection at the repo root).

**Pseudocode (NOT implementation):**
```
import subprocess
import sys
from pathlib import Path

from hello import greet

SCRIPT = Path(__file__).parent / "hello.py"


def test_hello_prints_hello_world() -> None:
    # Subprocess end-to-end test: preserves the pre-refactor regression check.
    # Maps to: US-5, FR-12, AT-3, AT-4, NFR-5 (timeout ≤ 5s), NFR-6.
    result = subprocess.run(
        [sys.executable, str(SCRIPT)],
        capture_output=True,
        text=True,
        timeout=5,
    )
    assert result.returncode == 0
    assert result.stdout.strip() == "hello world"
    assert result.stderr == ""


def test_greet_default_returns_hello_world() -> None:
    # Direct-call unit test for default argument.
    # Maps to: US-3, FR-10, FR-13, AT-1, AT-4, NFR-4 (no subprocess).
    assert greet() == "hello world"


def test_greet_with_custom_name_returns_hello_name() -> None:
    # Direct-call unit test for custom argument.
    # Maps to: US-4, FR-11, FR-13, AT-2, AT-4, NFR-4 (no subprocess).
    assert greet("ada") == "hello ada"
```

Design notes traceable to PRD:
- Imports `greet` at module load (FR-9). No try/except around the import — a missing or mis-named function MUST surface as a collection error.
- The subprocess test compares `result.stdout.strip()` to `"hello world"`. This passes whether `print` emits `\n` or `\r\n`, so it is robust on any POSIX or Windows host (NFR-2 still demands `\n`-only line endings in the source file itself).
- `timeout=5` honors NFR-5.
- No `@pytest.mark.skip`, `xfail`, or `skipif` decorators (FR-13).

## API Specification

### `hello.greet`
```python
def greet(name: str = "world") -> str: ...
```
- **Parameters**: `name` (`str`, optional; default `"world"`).
- **Returns**: `str` — exactly `"hello " + name`.
- **Raises**: Nothing the function itself defines; standard Python `TypeError` propagates if `name` is non-string and the f-string conversion fails on subsequent string operations (not in scope for tests — see NG4).
- **Examples**:
  - `greet()` → `"hello world"`
  - `greet("ada")` → `"hello ada"`

That is the entirety of the public API surface introduced by this request.
