## 0. Scope and Rigor Calibration

This is a **trivial-scale refactor** (one pure function, three pytest tests, two single-file targets). The verified current repo state already satisfies every PRD functional requirement and every TDD contract clause:

- `hello.py` contains exactly:
  ```python
  def greet(name: str = "world") -> str:
      return f"hello {name}"


  if __name__ == "__main__":
      print(greet())
  ```
- `test_hello.py` contains all three required tests with the assertions specified in TDD §3.4 plus the module-level `from hello import greet`.

Per the "Scale Rigor to Task Complexity" guideline:

- This spec specifies the **exact canonical contents** of both files (the contract surface is genuinely tiny and fully enumerable).
- It does **NOT** invent byte counts, length deltas, hex dumps, or fabricated error taxonomies — the function has no error path by design (TDD §6).
- Acceptance criteria are **behavioral and command-anchored** (`pytest` exit code, exact stdout strings via `grep -F`, `repr()` equality), not fragile arithmetic.

In the expected case the executor performs **read-only verification**; code is written only if a check fails, and only to restore the canonical forms below.

## 1. API Contracts

### 1.1 `hello.greet`

**Full signature (must compile and import without warnings):**

```python
def greet(name: str = "world") -> str:
    return f"hello {name}"
```

**Parameter contract:**

| Param  | Type  | Default   | Kind                       | Constraints                                                                                          |
|--------|-------|-----------|----------------------------|------------------------------------------------------------------------------------------------------|
| `name` | `str` | `"world"` | positional-or-keyword      | No leading `/` (NOT positional-only). No leading `*` (NOT keyword-only). No validation, no normalization. |

**Return contract:**

- Type: `str`.
- Value: equal byte-for-byte to the Python expression `"hello " + name`.
- A new `str` instance per call; no caching, no interning guarantees beyond CPython defaults.

**Preconditions:** None. Caller is expected to pass a `str`. Non-`str` inputs are explicitly out of scope (PRD NG2 / OQ-1) — no validation is performed.

**Postconditions:**

- The interpreter state is unchanged except for the returned object's allocation.
- No file, network, environment, logging, or stdout/stderr side effect occurs.

**Side effects:** None.

**Errors raised:** None by design. The function MUST NOT contain `raise`, `try`, `except`, `assert`, or `if`/validation branches.

**Usage examples (each must hold true after implementation):**

```python
from hello import greet

assert greet()             == "hello world"
assert greet("ada")        == "hello ada"
assert greet(name="bo")    == "hello bo"
assert greet("")           == "hello "        # trailing space, intentional (PRD NG2)
```

### 1.2 `hello` module `__main__` guard

**Full code (must appear at module bottom, after `greet`):**

```python
if __name__ == "__main__":
    print(greet())
```

**Constraints (all mandatory):**

- MUST call `print(greet())`. MUST NOT inline the string literal (`print("hello world")`) or duplicate the f-string.
- MUST NOT call `sys.exit(...)` — rely on the implicit exit code `0`.
- MUST NOT read `sys.argv`, environment variables, or stdin.
- MUST NOT configure `logging`.
- MUST NOT wrap the call in `try`/`except`.

### 1.3 Import-time purity contract

`hello.py` MUST contain only:

1. (Optional) one single-line docstring at the very top — permitted but not required.
2. The `def greet(...)` definition shown in §1.1.
3. Exactly one blank-line separator (PEP 8 allows two; one or two are both acceptable).
4. The `if __name__ == "__main__":` block shown in §1.2.

`hello.py` MUST NOT contain any of:

- `import` statements (none are needed).
- `__all__` assignment (ADR-5).
- Top-level `print(...)`, function calls, attribute lookups with side effects.
- Top-level `logging` configuration.
- Module-level constants other than what is implied by the function definition.

### 1.4 Canonical exact file body for `hello.py`

If the executor needs to write `hello.py` (only on divergence), it MUST write exactly the following bytes (final newline included):

```python
def greet(name: str = "world") -> str:
    return f"hello {name}"


if __name__ == "__main__":
    print(greet())
```

## 4. Test Specification (`test_hello.py`)

### 4.1 Canonical exact file body

If the executor needs to write `test_hello.py` (only on divergence), it MUST write exactly the following bytes (final newline included):

```python
import subprocess
import sys
from pathlib import Path

from hello import greet

SCRIPT = Path(__file__).parent / "hello.py"


def test_hello_prints_hello_world() -> None:
    result = subprocess.run(
        [sys.executable, str(SCRIPT)],
        capture_output=True,
        text=True,
        timeout=5,
    )
    assert result.returncode == 0
    assert result.stdout.strip() == "hello world"
    assert result.stderr == ""


def test_greet_default_returns_hello_world() -> None:
    assert greet() == "hello world"


def test_greet_with_custom_name_returns_hello_name() -> None:
    assert greet("ada") == "hello ada"
```

### 4.2 Test inventory (exact names — these are part of the contract)

| ID    | Function name                                          | Category    | Traces to (PRD FR)      |
|-------|--------------------------------------------------------|-------------|-------------------------|
| TC-1  | `test_hello_prints_hello_world`                        | integration | FR-5, FR-6, FR-9        |
| TC-2  | `test_greet_default_returns_hello_world`               | unit        | FR-2, FR-7              |
| TC-3  | `test_greet_with_custom_name_returns_hello_name`       | unit        | FR-3, FR-8              |

The three test function names above are part of the public contract (PRD Appendix A) and MUST NOT be renamed.

### 4.3 Test case details

#### TC-1: `test_hello_prints_hello_world` (PRESERVED VERBATIM)

- **Description:** Verify the CLI contract — running `python hello.py` as a subprocess prints exactly `hello world\n` on stdout, nothing on stderr, exit code 0.
- **Setup:** `SCRIPT = Path(__file__).parent / "hello.py"`. `sys.executable` provides the current interpreter.
- **Action:** `subprocess.run([sys.executable, str(SCRIPT)], capture_output=True, text=True, timeout=5)`.
- **Expected:**
  - `result.returncode == 0`.
  - `result.stdout.strip() == "hello world"`.
  - `result.stderr == ""`.
- **Category:** integration / subprocess smoke.
- **MUST NOT WEAKEN:** the three assertions above are the locked contract; the executor MUST NOT remove or relax any of them, MUST NOT change `timeout=5` upward without justification, MUST NOT drop `capture_output=True` or `text=True`.

#### TC-2: `test_greet_default_returns_hello_world`

- **Description:** Verify `greet()` with no arguments returns `"hello world"`.
- **Setup:** Module-level `from hello import greet`.
- **Action:** Call `greet()`.
- **Expected:** Return value `== "hello world"` (strict string equality).
- **Category:** unit.

#### TC-3: `test_greet_with_custom_name_returns_hello_name`

- **Description:** Verify `greet("ada")` returns `"hello ada"`.
- **Setup:** Module-level `from hello import greet`.
- **Action:** Call `greet("ada")`.
- **Expected:** Return value `== "hello ada"` (strict string equality).
- **Category:** unit.

### 4.4 Implicit / not-added tests

- **Silent-import coverage (FR-4):** covered implicitly because `from hello import greet` at the top of `test_hello.py` runs at pytest collection time; any stray top-level `print` in `hello.py` would surface as captured stdout. A dedicated `capsys` test (TDD §7.4) MUST NOT be added unless explicitly requested in spec_review or code_review.
- **Parametrized form:** MUST NOT replace TC-2 + TC-3 with a single `@pytest.mark.parametrize` test (ADR-4).
- **Non-string input tests:** MUST NOT be added (PRD NG2, OQ-1).
- **`__all__` assertions:** MUST NOT be added (ADR-5).

### 4.5 Test fixtures / mocks / setup-teardown

None. No `conftest.py`, no fixtures, no monkeypatching, no mocks.
