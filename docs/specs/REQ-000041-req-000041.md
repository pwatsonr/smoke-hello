## 1. Intent (one-paragraph summary)

`hello.py` must export a pure function `greet(name: str = "world") -> str` that returns `f"hello {name}"`, and its `if __name__ == "__main__":` block must do exactly `print(greet())`. `test_hello.py` must contain exactly three pytest test functions covering the default call, a custom-name call, and a CLI subprocess invocation. The CLI contract — `python hello.py` → stdout `hello world\n`, exit 0, empty stderr — must be bit-for-bit preserved. No new files, no new imports beyond the standard library, no input validation, no argparse, no packaging changes.

If the working tree already matches this spec (it does as of 2026-06-20), the executor performs verification only and ships no code edits. If drift exists, the executor applies the minimal patch to restore the contract below.

## 2. API Contracts

### 2.1 `hello.greet`

**Module:** `hello` (file `hello.py` at repo root).

**Signature (Python, must match exactly):**

```python
def greet(name: str = "world") -> str: ...
```

**Parameters:**

| Name | Type | Default | Constraints | Notes |
| --- | --- | --- | --- | --- |
| `name` | `str` | `"world"` | None enforced at runtime. Type annotation is documentary (PEP 484); Python does not type-check it. | Caller-supplied. No validation, no normalization, no escaping. |

**Returns:** `str` — exactly the value of the Python f-string `f"hello {name}"`. Equivalently: the 6-character literal `"hello "` concatenated with the string value of `name`.

**Implementation body (canonical, ADR-002):**

```python
return f"hello {name}"
```

`"hello " + name` is **not** an acceptable substitute — ADR-002 chose the f-string form for verbatim traceability to PRD FR-3. For any `name: str`, the two expressions are observably equal, but the executor MUST emit the f-string form to satisfy ADR-002.

**Preconditions:** None. The function may be called with any value; behavior for non-`str` is undefined and out of scope (TDD ADR-004).

**Postconditions:**
- Returns a fresh `str` equal to `f"hello {name}"`.
- No global state is read or written.
- No I/O is performed (no stdout, no filesystem, no network, no clock, no random).
- Never raises for any `str` input.

**Purity invariants (TDD §3.1, NFR-4):**
- No module-level mutable state introduced or touched.
- No imports added inside the function or at module scope (the module must remain import-free).

**Usage examples (all must hold after implementation):**

```python
from hello import greet

assert greet() == "hello world"
assert greet("ada") == "hello ada"
assert greet(name="ada") == "hello ada"   # kwarg form
assert greet("") == "hello "              # empty-string edge: returns "hello " (6 chars, trailing space)
```

The empty-string example is **documentary** — it describes the contract, not a required test case. It MUST NOT be added to `test_hello.py` (out of scope per PRD §2.2 / TDD §12 follow-ups).

### 2.2 `hello` module `__main__` entry point

**Required `__main__` block (exact form):**

```python
if __name__ == "__main__":
    print(greet())
```

**Constraints:**
- No `argparse`, no `sys.argv` inspection, no environment variables, no logging configuration.
- `print(greet())` — not `print("hello world")`, not `sys.stdout.write(greet() + "\n")` — must use `print` so that the newline and stream are Python's standard.
- The block must be the last top-level statement in the file.

**Observable CLI contract:**

| Property | Value |
| --- | --- |
| Command | `python hello.py` (or `python3 hello.py`, or `<sys.executable> hello.py`) |
| Exit code | `0` |
| stdout | exactly `hello world\n` (lowercase, ASCII, single trailing newline from `print`) |
| stderr | empty string (no warnings, no tracebacks) |

### 2.3 Module-level invariants for `hello.py`

- **No `import` statements.** The module must have zero `import` and zero `from ... import ...` statements. (Enforced by acceptance test 7.)
- **LOC budget:** ≤ 10 non-blank lines (PRD §8). The canonical implementation is 5 non-blank lines.
- **No additional public symbols.** Only `greet` and the `__main__` guard. No helpers, no constants, no `__all__`.
- **Python ≥ 3.6** (f-string requirement; ADR-002). No version pin file needs to be added.

### 2.4 `test_hello.py` module layout

**Required imports (exact set, order may vary but standard pep8 grouping is expected):**

```python
import subprocess
import sys
from pathlib import Path

from hello import greet
```

**Required module-level constant:**

```python
SCRIPT = Path(__file__).parent / "hello.py"
```

This name MUST be `SCRIPT` (uppercase). It is referenced by the subprocess test.

**Allowed additions:** None. No fixtures, no `conftest.py`, no parametrize decorators, no helper functions.

## 5. Test Cases

The three tests below are the entire required test surface. They MUST be the only three tests in `test_hello.py`. Each test is module-level, synchronous, takes no arguments other than `self`-less zero, and uses only stdlib + `hello.greet`.

### TC-1 — `test_greet_default_returns_hello_world`

- **ID:** TC-1
- **Description:** Verifies `greet()` with no arguments returns the default greeting (PRD FR-2, FR-7; TDD §3.2).
- **Category:** unit
- **Setup:** `from hello import greet` at module scope. No fixtures.
- **Action:** Call `greet()`.
- **Expected:** Return value equals the string `"hello world"` (lowercase, single space, no trailing newline, no surrounding whitespace).
- **Required body (canonical):**

  ```python
  def test_greet_default_returns_hello_world() -> None:
      assert greet() == "hello world"
  ```

### TC-2 — `test_greet_with_custom_name_returns_hello_name`

- **ID:** TC-2
- **Description:** Verifies `greet("ada")` returns the personalized greeting (PRD FR-3, FR-8; TDD §3.2).
- **Category:** unit
- **Setup:** `from hello import greet` at module scope.
- **Action:** Call `greet("ada")`.
- **Expected:** Return value equals the string `"hello ada"`.
- **Required body (canonical):**

  ```python
  def test_greet_with_custom_name_returns_hello_name() -> None:
      assert greet("ada") == "hello ada"
  ```

### TC-3 — `test_hello_prints_hello_world`

- **ID:** TC-3
- **Description:** Verifies the CLI contract end-to-end via subprocess (PRD FR-4, FR-5, FR-9; TDD §3.2, ADR-003).
- **Category:** integration (CLI subprocess)
- **Setup:**
  - `SCRIPT = Path(__file__).parent / "hello.py"` at module scope.
  - `import subprocess`, `import sys`.
- **Action:** Run

  ```python
  subprocess.run(
      [sys.executable, str(SCRIPT)],
      capture_output=True,
      text=True,
      timeout=5,
  )
  ```

- **Expected (all three assertions, in any order):**
  - `result.returncode == 0`
  - `result.stdout.strip() == "hello world"`
  - `result.stderr == ""`
- **Constraints (MUST):**
  - First argv element is `sys.executable` (NOT the literal `"python"` or `"python3"`) — ADR-003.
  - Script path passed via `str(SCRIPT)` derived from `Path(__file__).parent / "hello.py"` — location independence.
  - `timeout=5` literal — NFR-1.
  - `shell=False` (the default; do not pass `shell=True`) — security (TDD §8).
- **Required body (canonical):**

  ```python
  def test_hello_prints_hello_world() -> None:
      result = subprocess.run(
          [sys.executable, str(SCRIPT)],
          capture_output=True,
          text=True,
          timeout=5,
      )
      assert result.returncode == 0
      assert result.stdout.strip() == "hello world"
      assert result.stderr == ""
  ```

- Pytest reports exactly `3 passed`.
