## API Contracts

### `greet(name: str = "world") -> str`

**Module**: `hello` (top-level module at the repo root; resolved as `hello` when pytest / `python` is invoked from `/Users/pwatson/codebase/smoke-hello`).

**Full signature** (must match verbatim, including the type annotations — TDD ADR-1, PRD OQ-3):

```python
def greet(name: str = "world") -> str:
    return f"hello {name}"
```

**Parameters**:

| Name | Type | Default | Constraint |
| --- | --- | --- | --- |
| `name` | `str` (annotation only; not enforced at runtime) | `"world"` (lowercase ASCII literal) | None. Any object supporting `__format__` is accepted; PRD FR-2 / OQ-2 leave non-`str` and empty-string behavior unspecified, and the implementation MUST NOT add validation. |

**Return**:

- Type: `str`.
- Value: the exact string `f"hello {name}"`, i.e. the four ASCII characters `h`, `e`, `l`, `l`, `o` followed by a single ASCII space `0x20`, followed by `str(name)` as interpolated by Python's f-string formatting (which for `str` inputs is the value itself).

**Preconditions**: None.

**Postconditions**:

- Pure: no I/O, no global state mutation, no time/random dependence (TDD §API Specification, PRD NFR-1).
- For the default call: `greet() == "hello world"` (PRD FR-1, FR-2; AT-1).
- For a `str` argument: `greet(s) == "hello " + s` for every `str s` (PRD FR-3; AT-2).

**Side effects**: None.

**Errors raised**: None contractually. The implementation does not catch or raise. Passing an object whose `__format__` raises will propagate that exception unchanged; this is not a documented contract and MUST NOT be tested for.

**Usage example**:

```python
from hello import greet

greet()        # -> "hello world"
greet("ada")   # -> "hello ada"
```

### Module-level `__main__` guard in `hello.py`

**Required shape** (verbatim, TDD §"Canonical Source Shape"):

```python
if __name__ == "__main__":
    print(greet())
```

**Contract**:

- When `hello.py` is executed as a script (`python hello.py`), the program writes the eight bytes `hello world\n` (the trailing `\n` is supplied by `print`) to stdout, writes nothing to stderr, and exits 0 (PRD FR-5, FR-7, AT-3).
- When `hello` is imported (`python -c "import hello"` or `from hello import greet`), the module produces no stdout and no stderr (PRD FR-6, AT-4, US-4).
- The `__main__` block contains exactly one statement: `print(greet())`. No additional logging, argparse, sys.exit, or banner text (PRD FR-6, TDD ADR-3).

### `hello.py` module-level constraints

- The module MUST NOT contain any `import` or `from ... import` statement (PRD FR-8, TDD §"Canonical Source Shape"). Verified by the static grep in §Test Cases below.
- The module MUST NOT contain any top-level executable code other than the `def greet(...)` definition and the `if __name__ == "__main__":` guard (PRD FR-6).
- Total length SHOULD remain ≤ 15 lines (PRD NFR-3); the canonical shape is 6 lines of code plus blank separators.

### Canonical `test_hello.py` shape (TDD §"Test Module Shape")

```python
import subprocess
import sys
from pathlib import Path

from hello import greet

SCRIPT = Path(__file__).parent / "hello.py"


def test_hello_prints_hello_world() -> None:
    result = subprocess.run(
        [sys.executable, str(SCRIPT)],
        capture_output=True,
        text=True,
        timeout=5,
    )
    assert result.returncode == 0
    assert result.stdout.strip() == "hello world"
    assert result.stderr == ""


def test_greet_default_returns_hello_world() -> None:
    assert greet() == "hello world"


def test_greet_with_custom_name_returns_hello_name() -> None:
    assert greet("ada") == "hello ada"
```

## Implementation Notes

- **Codebase conventions discovered**:
  - The repo has no `pyproject.toml`, no `src/` layout, no `conftest.py`, no `__init__.py`. `hello` resolves as a top-level module when `python` or `pytest` is invoked from the repo root (PRD TC-4, TDD §Codebase Survey).
  - Prior closed requests (`REQ-000023`, `REQ-000024` under `.autonomous-dev/_done_requests/`) followed the same canonical shape; the spec intentionally mirrors them to minimize diff (TDD ADR-2).

- **Patterns to follow**:
  - Use `subprocess.run([sys.executable, str(SCRIPT)], ...)` rather than hard-coding `"python"` so the test runs under the same interpreter pytest is using (already pinned in TC-3).
  - Resolve the script path with `Path(__file__).parent / "hello.py"` rather than relying on the cwd; this keeps TC-3 stable under any cwd.

- **Gotchas**:
  - **Do not add input validation, argparse, packaging, `if not name:` fallbacks, or `@pytest.mark.parametrize`.** PRD non-goals and TDD ADR-1/ADR-2/ADR-3 explicitly forbid this. Doing so would fail spec_review even though the tests might pass.
  - **Do not weaken the subprocess assertions** in TC-3. All three (`returncode == 0`, `stdout.strip() == "hello world"`, `stderr == ""`) are pinned by PRD FR-9 and TDD §"Test Module Shape". In particular, do not replace `result.stderr == ""` with a truthy check, and do not drop the `returncode` check.
  - **Do not rename the test functions.** TC-8 (`pytest -k greet`) depends on the two greet-suffixed names; renaming them risks falling below the ≥ 2-selected threshold (PRD AT-6).
  - **The expected source diff is empty.** TDD ADR-3 and PRD OQ-4 explicitly permit a no-op code phase. The executor MUST NOT add a whitespace or comment change purely to produce a non-empty diff.
  - **`pytest` binary may not be on PATH.** Fall back to `python -m pytest` (already noted in TC-7).

- **Reference implementations in the codebase**:
  - `hello.py` (current contents, 7 lines including the trailing newline) — matches the canonical shape verbatim.
  - `test_hello.py` (current contents, 28 lines including the trailing newline) — matches the canonical test-module shape verbatim.
  - `.autonomous-dev/_done_requests/REQ-000023/` and `REQ-000024/` — prior closed requests in this repo that produced/maintained the same shape.

- **Open questions**: None. PRD OQ-1..OQ-4 are resolved by TDD ADR-1..ADR-3 (two-function shape; no extra edge-case tests; type annotations kept; no-op code phase permitted).
