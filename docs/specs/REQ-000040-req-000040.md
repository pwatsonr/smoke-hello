## 2. API Contract

### 2.1 `hello.greet`

| Property | Value |
|---|---|
| Kind | Public module-level function in `hello.py` |
| Signature | `def greet(name: str = "world") -> str` |
| Parameters | `name: str` — defaults to the literal string `"world"`; no validation, no coercion |
| Returns | The string produced by the f-string `f"hello {name}"` (i.e. literal `hello`, a single ASCII space `0x20`, then `name`) |
| Raises | Does not raise for any `str` input. Behavior for non-`str` inputs is intentionally undefined (PRD OQ-1). |
| Side effects | None. No I/O, no logging, no global mutation. |
| Determinism | Pure function of `name`. |
| Import safety | Importing `hello` MUST NOT print anything or otherwise produce observable effects (FR-10). |

#### Usage examples

```python
from hello import greet

greet()              # -> "hello world"
greet("ada")         # -> "hello ada"
greet(name="grace")  # -> "hello grace"
```

### 2.2 `hello.__main__` block

| Property | Value |
|---|---|
| Trigger | Only when the module's `__name__` equals `"__main__"` (i.e. `python hello.py` or `python -m hello`). |
| Behavior | Calls `print(greet())`, which writes `hello world\n` to stdout. |
| Exit code | `0` on normal completion. |
| Stderr | Empty. |

### 2.3 No other public API

This change adds **no other** importable names beyond `greet` (and the
incidental module-level `__name__` guard, which is not part of the public
API). No CLI flags, no environment variables, no config files, no logging
configuration.

## 3. Reference Target — `hello.py`

The executor MUST produce a file with **exactly** the following content (UTF-8,
LF line endings, terminating newline):

```python
def greet(name: str = "world") -> str:
    return f"hello {name}"


if __name__ == "__main__":
    print(greet())
```

Constraints (each is a hard requirement):

- The first top-level definition is `def greet(name: str = "world") -> str:`.
- The function body is a single `return f"hello {name}"` statement.
- The only other top-level statement is the `if __name__ == "__main__":`
  guard, whose body is exactly `print(greet())`.
- No additional imports, no `from __future__` imports, no module docstring,
  no `__all__`, no logging, no shebang line.
- File ends with a single trailing newline.

## 4. Reference Target — `test_hello.py`

The executor MUST produce a file with **exactly** the following content (UTF-8,
LF line endings, terminating newline):

```python
import subprocess
import sys
from pathlib import Path

from hello import greet

SCRIPT = Path(__file__).parent / "hello.py"


def test_hello_prints_hello_world() -> None:
    result = subprocess.run(
        [sys.executable, str(SCRIPT)],
        capture_output=True,
        text=True,
        timeout=5,
    )
    assert result.returncode == 0
    assert result.stdout.strip() == "hello world"
    assert result.stderr == ""


def test_greet_default_returns_hello_world() -> None:
    assert greet() == "hello world"


def test_greet_with_custom_name_returns_hello_name() -> None:
    assert greet("ada") == "hello ada"
```

Constraints (each is a hard requirement):

- Exactly three `def test_*` functions, with the names listed above and in
  this order.
- `test_hello_prints_hello_world` MUST use
  `subprocess.run([sys.executable, str(SCRIPT)], capture_output=True, text=True, timeout=5)`
  with the four assertions shown (returncode, stdout.strip equals, stderr
  empty — but `result.stdout.strip() == "hello world"` and `result.stderr == ""`
  as written). FR-9 forbids weakening any of these assertions.
- `test_greet_default_returns_hello_world` MUST assert exactly
  `greet() == "hello world"`.
- `test_greet_with_custom_name_returns_hello_name` MUST assert exactly
  `greet("ada") == "hello ada"`.
- The top-level `from hello import greet` is required (it doubles as the
  FR-10 import-side-effect guard).
- No `tests/` package, no `conftest.py`, no `pyproject.toml`, no
  `pytest.ini`, no fixtures, no parameterization (TDD D5).
