### Proportionality Note

Per the rigor-to-complexity guidance: this is a **trivial refactor of a
two-file repository** (`hello.py`, `test_hello.py`) that is already
**materially present in the working tree** (verified by inspection during
plan authoring — see Appendix A). The TDD §11 explicitly describes the
implementation as **verify-and-ratify**, not ground-up coding. Accordingly,
this plan is intentionally small: **2 tasks, 1 track, no dependency graph
beyond a single linear edge**. Inflating it with fake parallelism, fabricated
risk surface, or per-section ceremony for non-existent design surface would
be a defect.

## Task List

### TASK-001 — Ratify `hello.py` against the TDD reference target

- **ID**: TASK-001
- **Title**: Ratify `hello.py` matches the §11.1 reference target.
- **Description**: Verify that `hello.py` defines exactly one top-level
  function `greet(name: str = "world") -> str` returning `f"hello {name}"`
  and that the only other top-level statement is the
  `if __name__ == "__main__": print(greet())` guard. If any deviation is
  found (missing type hint, wrong default, wrong format string, unguarded
  print, extra imports, extra top-level code), overwrite the file with the
  exact body from TDD §11.1. Traces to TDD §3.1, §3.2, §11.1; PRD FR-1, FR-2,
  FR-3, FR-4, FR-5, FR-6, FR-10, NFR-3, NFR-4, NFR-6, NFR-7.
- **Files**:
  - `hello.py` (modify only if it deviates from the TDD §11.1 reference).
- **Dependencies**: none.
- **Acceptance Criteria**:
  1. `python -c "from hello import greet; assert greet() == 'hello world'; assert greet('ada') == 'hello ada'"` exits 0 with empty stdout (proves importability with no side effects — FR-10 — and FR-3, FR-4).
  2. `python hello.py` prints exactly `hello world\n` to stdout, empty stderr, exit code 0 (FR-5, FR-6, NFR-6).
  3. `python -m py_compile hello.py` exits 0 (syntactic well-formedness).
  4. `hello.py` is ≤ 30 non-blank LoC (NFR-7); the reference body is 6 LoC.
  5. `hello.py` contains the literal substring `def greet(name: str = "world") -> str:` and the literal substring `if __name__ == "__main__":`.
- **Lint/Test Commands**:
  ```bash
  python -m py_compile hello.py
  python -c "from hello import greet; assert greet() == 'hello world'; assert greet('ada') == 'hello ada'"
  python hello.py
  ```
- **Estimated Effort**: 0.25 hour (≈ 15 minutes, including the 20% buffer;
  expected actual time < 3 minutes because the file already matches).
- **Track**: T1 (only track).
- **Risks**:
  - **R1 (low)**: A future code-style hook (black/ruff) could be added in
    parallel and reformat the file; not in scope for this request. Mitigation:
    no action — out of scope per TC-1 and PRD NG3.
  - **R2 (low)**: An executor might add `from __future__ import annotations`
    or other extra imports. Mitigation: acceptance criterion 4 (≤ 30 LoC) and
    review by code_review phase against TDD §11.1 character-identical target.

### TASK-002 — Ratify `test_hello.py` against the TDD reference target

- **ID**: TASK-002
- **Title**: Ratify `test_hello.py` contains the three required tests.
- **Description**: Verify that `test_hello.py` (repo root) contains exactly
  the three pytest tests enumerated in TDD §7.1:
  `test_hello_prints_hello_world` (subprocess), `test_greet_default_returns_hello_world`,
  and `test_greet_with_custom_name_returns_hello_name`. The subprocess test
  MUST be preserved verbatim per FR-9. The two unit tests MUST assert exactly
  `greet() == "hello world"` and `greet("ada") == "hello ada"` respectively.
  If any test is missing, renamed, or has weakened assertions, overwrite the
  file with the exact body from TDD §11.1. Traces to TDD §3.3, §7.1, §11.1;
  PRD FR-7, FR-8, FR-9, FR-10, US-4.
- **Files**:
  - `test_hello.py` (modify only if it deviates from the TDD §11.1 reference).
- **Dependencies**: TASK-001 (the unit tests `from hello import greet`, so
  `hello.py` must already conform).
- **Acceptance Criteria**:
  1. `pytest -q` from `/Users/pwatson/codebase/smoke-hello` reports `3 passed`, `0 failed`, exit code 0.
  2. `test_hello.py` contains the function names `test_hello_prints_hello_world`, `test_greet_default_returns_hello_world`, `test_greet_with_custom_name_returns_hello_name` (verified by `grep -E "^def test_" test_hello.py | wc -l` returning `3`).
  3. The subprocess test uses `subprocess.run([sys.executable, str(SCRIPT)], capture_output=True, text=True, timeout=5)` (FR-9 preservation).
  4. `python -m py_compile test_hello.py` exits 0.
  5. `pytest` total wall time < 5 s (NFR-1).
- **Lint/Test Commands**:
  ```bash
  python -m py_compile test_hello.py
  pytest -q
  grep -E "^def test_" test_hello.py | wc -l   # must be 3
  ```
- **Estimated Effort**: 0.25 hour (≈ 15 minutes, including the 20% buffer;
  expected actual time < 2 minutes because the file already matches).
- **Track**: T1.
- **Risks**:
  - **R3 (low)**: Test isolation — if `hello.py` were edited to print at
    import time, every test would emit `hello world` to captured stdout but
    still pass (pytest does not fail on stray output by default). Mitigation:
    TASK-001 acceptance criterion 1 catches this before TASK-002 runs.
  - **R4 (low)**: An executor might add a `tests/` directory or a
    `conftest.py`. Mitigation: TDD D5 explicitly forbids this; code_review
    will reject any such additions.
