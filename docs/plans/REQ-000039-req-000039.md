no data model, no integration point, and no non-trivial logic** beyond a single
f-string. The TDD itself prescribes a single atomic task (T-1), and the current
repository state already byte-matches PRD Appendices A & B (verified by

## Task List

### TASK-001 — Verify-and-restore target shape; run acceptance tests
- **ID**: TASK-001
- **Title**: Verify-and-restore `hello.py` & `test_hello.py`; run acceptance suite
- **Description**: Per TDD §"Implementation Plan / Task T-1", confirm both production and test files match the exact shapes in PRD Appendices A & B (reproduced in TDD §"Detailed Design"). If either file has drifted, overwrite it with the canonical content from the corresponding appendix. Then run the six acceptance verifications from the TDD §"Testing Strategy" table.
- **Files**:
  - `/Users/pwatson/codebase/smoke-hello/hello.py` (verify; create/overwrite only if drift detected)
  - `/Users/pwatson/codebase/smoke-hello/test_hello.py` (verify; create/overwrite only if drift detected)
- **Dependencies**: None.
- **Acceptance Criteria** (all must hold; map directly to PRD AT-1…AT-6):
  1. `python -c "from hello import greet; assert greet() == 'hello world'"` exits `0` (AT-1, FR-4).
  2. `python -c "from hello import greet; assert greet('ada') == 'hello ada'"` exits `0` (AT-2, FR-5).
  3. `python hello.py` prints exactly `hello world\n` to stdout, empty stderr, exit `0` (AT-3, FR-6, FR-7, NFR-6).
  4. `pytest -q` collects and passes **exactly 3** tests, no skips/xfails (AT-4, FR-13).
  5. `python -c "import hello"` produces no stdout (AT-5, FR-8, NFR-7 — module is side-effect free).
  6. `git status --porcelain` shows changes only to `hello.py`, `test_hello.py`, and pipeline-owned artifacts under `.autonomous-dev/` and `docs/` (AT-6, FR-14).
  7. Both files are UTF-8, LF-only line endings, single trailing newline (NFR-2).
- **Lint/Test Commands** (run in repo root `/Users/pwatson/codebase/smoke-hello`):
  ```bash
  # Functional / acceptance:
  python -c "from hello import greet; assert greet() == 'hello world'"
  python -c "from hello import greet; assert greet('ada') == 'hello ada'"
  python hello.py                 # expect: hello world
  python -c "import hello"        # expect: no output
  pytest -q                       # expect: 3 passed
  git status --porcelain          # expect: only the two target files + daemon dirs

  # Optional sanity (no lint config is pinned in-repo; skip if tool absent):
  python -m py_compile hello.py test_hello.py
  ```
- **Estimated Effort**: 5 minutes expected (zero edits needed today) + 5 minutes verification + 5 minutes (20%) buffer ≈ **15 minutes total**.
- **Track**: T1 (only track).
- **Risks**:
  - **R-1 (low)**: Between plan authoring and code execution, an unrelated process modifies one of the two files. *Mitigation*: TASK-001 begins with a `Read` of both files and an explicit diff against the TDD pseudocode; on mismatch, the executor overwrites with the canonical content from PRD Appendix A / B (also reproduced verbatim in TDD §"Detailed Design").
  - **R-2 (low)**: `pytest` is not available in the execution environment. *Mitigation*: TDD TC-2/TC-4 declare pytest is supplied by the smoke-test environment. If absent, the executor reports a blocker; it MUST NOT pin pytest by introducing `pyproject.toml` / `requirements.txt` (forbidden by TC-3/TC-4, FR-14).
  - **R-3 (low)**: Trailing-newline / line-ending drift introduced by an editor. *Mitigation*: TASK-001 explicitly verifies UTF-8 + LF + single trailing newline as criterion 7.
