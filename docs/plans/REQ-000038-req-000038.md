## 0. Scope and Rigor Calibration

This is a **trivial-scale change**. The verified current repo state already satisfies every PRD functional requirement and every TDD contract clause:

- `hello.py` already defines `def greet(name: str = "world") -> str: return f"hello {name}"` and a `__main__` guard `print(greet())`.
- `test_hello.py` already contains all three required tests: `test_hello_prints_hello_world`, `test_greet_default_returns_hello_world`, `test_greet_with_custom_name_returns_hello_name`.

Per the "Scale Rigor to Task Complexity" guideline, this plan therefore stays minimal. There is **no real dependency graph** beyond a linear chain, **no parallel track structure**, and **no risk surface** beyond "the verification commands might surprisingly fail." Sections that would inflate the plan with manufactured content are marked **N/A — single-track verification change**.

Each task below is expected to be a **verification-only no-op** in the common case; an executor will write code only if a check fails.

## 1. Task List

### TASK-001: Verify `hello.py` matches TDD §3.1–§3.3

- **ID:** TASK-001
- **Title:** Verify (and if needed correct) `hello.py`
- **Description:** Read `hello.py` and confirm it contains exactly:
  1. `def greet(name: str = "world") -> str:` returning `f"hello {name}"`.
  2. `if __name__ == "__main__": print(greet())`.
  3. No other top-level statements (no top-level `print`, no top-level calls, no logging config), per TDD §3.3.
  If any clause is missing or different, rewrite `hello.py` to the canonical body shown in TDD §3.1 + §3.2. Do not add a module docstring with doctest examples. Do not add `__all__` (ADR-5). Do not change parameter kind (ADR-2).
- **Files:** `hello.py` (read; modify only if a discrepancy is found).
- **Dependencies:** None.
- **Acceptance Criteria:**
  - `python -c "import hello"` exits 0 with no stdout and no stderr (silent import, FR-4).
  - `python -c "import hello; print(repr(hello.greet()))"` prints `'hello world'`.
  - `python -c "import hello; print(repr(hello.greet('ada')))"` prints `'hello ada'`.
  - `python hello.py` prints exactly `hello world\n` on stdout, empty stderr, exit code `0`.
- **Lint/Test Commands:**
  ```bash
  cd /Users/pwatson/codebase/smoke-hello
  python -c "import hello"
  python hello.py
  ```
- **Estimated Effort:** 5 minutes.
- **Track:** Track 1 (only track).
- **Risks:**
  - **R-001 (low):** Someone edits `hello.py` between verification and the final E2E run. Mitigation: TASK-003 re-runs the CLI assertion at the end.
